# 磁轴试验

这部分仍是硬件试验。普通键盘模式不需要开启它。

目前读取 VID 0416 / PID 7372 的厂商 HID 接口，通过公开的 KeyAxis 协议信息实现。开启命令涉及临时参数，不能保证适用于所有同标识键盘，也不能保证不影响当前键盘设置。不会发送刷写固件或恢复出厂命令。参考：https://github.com/RigZeeel/KeyAxis/blob/main/PROTOCOL.md 。本项目没有复制 KeyAxis 的程序代码。

启动后，先单独慢按一个键到底再松开，让软件尝试对应物理键与内部位置。也可以用“全部校准”或 Ctrl 多选后的“校准选中键”，按提示依次操作。一次按多个键时会放弃不确定的识别。

建立对应关系后，程序用有效行程 15% 到 55% 之间的运动估算起音速度，再映射为力度。缺乏可靠样本时使用默认力度。它不能测量触底之后的持续压力。

停止、最小化或退出时，程序尝试关闭行程流并释放句柄。崩溃时不能保证发送关闭命令；写入成功也不等于确认硬件所有状态已经恢复。停止失败时按界面提示处理，必要时自行拔插键盘。

性能方面，HID 使用独立线程和有界事件队列，音频回调不执行 HID 读写。尚未测出可靠的端到端延迟数据，离线渲染耗时不能当作实机延迟。
